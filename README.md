# Configuring Static Routes

## Overview

This lab demonstrates how to configure IPv4 static routes to connect different networks.

## Objectives

* Configure IPv4 addressing
* Configure static routes
* Understand next-hop routing
* Verify routing tables
* Test network connectivity

## Tools

* Cisco Packet Tracer
* Cisco IOS

## Outcome

Successfully configured static routing and established communication between remote networks.
